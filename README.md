# VitaSurf

A lightweight, HTTPS-only browser for PS Vita homebrew, with a built-in GitHub mode.

## Browsing
- HTTPS only (http:// is upgraded), TLS 1.2+, certificates checked against a bundled CA list
- Shows text, headings, lists, code and links (no images, JavaScript or forms)
- Tabs (up to 9) and bookmarks (saved to `ux0:data/VitaSurf/bookmarks.txt`)

## Touch
- **Tap** a link to open it; **drag** to scroll (with momentum)
- **Pinch** with two fingers to make text bigger or smaller (remembered between launches)
- **Swipe in from the left edge** to go back, **from the right edge** to go forward
- **Hold a link** for a menu: Open, Open in new tab, Bookmark link, Show address
- **Pull down** at the top of a page to refresh
- Top bar: back, forward, reload, home, address, star (bookmark), list (bookmarks), tab count (tab switcher)

## GitHub mode
github.com needs a full JavaScript browser, so VitaSurf shows GitHub through GitHub's API instead.
Open the **GitHub** tile, type `gh owner/repo` or `gh username` in the address bar, or open any
github.com link.

- Search repositories, browse a user's repositories
- Repository page with README, file browser, code viewer
- Releases, with downloads saved to `uma0:data/VitaSurf/downloads` (or `ux0:` if there's no uma0)
- Optional sign-in with a personal access token for private repositories and a higher request limit
  (60 requests per hour without signing in, 5000 with). The token is stored in
  `ux0:data/VitaSurf/github_token.txt` and only ever sent to api.github.com.

## Buttons
Triangle = address/search, Square = reload, L / Circle = back, R = forward, Start = tabs,
Cross = bookmark page, Select = home, D-pad / right stick = scroll, Circle = cancel a download.

## Build
Push to GitHub; Actions builds `VitaSurf.vpk` (download it from the run's artifacts).
LiveArea images are generated by `tools/make_livearea.py`.
